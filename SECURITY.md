# Security Policy

## Project Status

**WIOT is currently under active development and has not yet reached a stable release.**  
As such, no formal security audits have been performed and its APIs may change at any time. Use in production is not recommended at this stage.

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in WIOT, please report it **privately**.

- Email: [steve@qoogy.fr](mailto:steve@qoogy.fr)
- Do **not** open a public issue for security concerns.
- Please provide as much detail as possible (e.g., version/commit, steps to reproduce, potential impact, affected components, etc.).

We aim to respond within **5 business days**.

---

## Scope and Limitations

At this stage:

- There is no formal guarantee of stability or support for security issues.
- Dependencies are updated regularly, but no strict audit or review process is enforced.
- Hardening, sandboxing, and secure-by-default configurations may still be in progress.

---

## Responsible Disclosure

We appreciate responsible disclosure and will credit any reporter who helps improve the security of the project.

If the project evolves toward a production-ready release, a formal disclosure process and CVE handling policy will be introduced.

---

## Thank You

Thank you for helping us make WIOT safer and more secure.
